# 落点 V3 · 升学星图

星图探索、分数定位、专业与院校档案、专业组对比、志愿工作台。手机采用底部导航、全屏档案、底部筛选抽屉、逐层返回、触摸分数尺与排序手柄；夜空和日光两种主题，支持课堂演示和系统减少动态效果。

访问：<https://yusheng266186-beep.github.io/sichuan-gaokao-2026/v3/>

## 运行与维护

生产环境为纯静态网页，无应用运行依赖、外部字体、CDN 脚本和登录要求。浏览器本地保存定位、偏好和工作台；查询地址可以分享，个人清单需通过 JSON 备份传递。

```bash
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000/v3/

python3 tools/build-v3.py          # 从原始数据生成 V3 发布包，并逐字段核对
python3 tools/build-v3.py --check  # 只核对，不改写任何文件
node --test tests/v3-core.test.cjs
```

浏览器回归使用开发依赖 Playwright：

```bash
npm ci
npx playwright install chromium
npm run test:browser
# 可选：V3_SCREENSHOT_DIR=/tmp/luodian-preview npm run test:browser
```

测试自行启动本地 HTTP 服务。受限环境可用 `V3_BROWSER_EXECUTABLE` 指定已有 Chromium；`V3_BROWSER_SINGLE_PROCESS=1` 用于无 Unix socket 的 headless-shell 环境。开发依赖不参与线上加载。

## 架构

| 层       | 文件                   | 职责                                                                                                          |
| -------- | ---------------------- | ------------------------------------------------------------------------------------------------------------- |
| 数据发布 | `../tools/build-v3.py` | 验证原数据关系，生成目录、元数据、分包与 SHA-256 清单，完整重建五份输入做相等检查                             |
| 数据读取 | `data.js`              | 首屏只读取检索目录；完整字典和院校分包按需加载；校验长度、版本与哈希；请求去重、失败重试、最多缓存 8 个院校包 |
| 匹配规则 | `core.js`              | 纯函数：分数与位次、冲稳保、选科、交叉筛选、稳定标识、清单作用域与诊断，可独立执行测试                        |
| 界面交互 | `app.js`               | 查询状态、四个入口、档案导航、对比、志愿排序与备份；防止过期详情请求覆盖新页面                                |
| 动效预算 | `motion.js`            | 数字过渡、粒子、指针反馈；手机减少粒子与分辨率，限制帧率；页面隐藏时暂停，尊重减少动态效果设置                |
| 响应布局 | `style.css`            | 桌面侧栏和手机底部导航分别布局；独立手机星图坐标、安全区、键盘状态、全屏档案、抽屉及打印布局                  |

## 无损数据结构

原始 `data/*.js` 仍是事实入口，生成 V3 时不改写这些文件。

| 原始数据       | V3 存储位置                      | 保留方式                                                                        |
| -------------- | -------------------------------- | ------------------------------------------------------------------------------- |
| `meta.js`      | `data/meta.json`                 | 整个对象：全部字典、7 份历史/当年分段表、标签、来源版本、生成时间与其他元字段   |
| `schools.js`   | `data/schools/00.json`–`36.json` | 2,308 个完整院校对象及原序号；院校代码不同的招生记录不合并                      |
| `groups.js`    | `data/catalog.json`              | 12,275 行，每行原始 22 字段，保持原顺序                                         |
| `offerings.js` | 院校分包的 `offerings`           | 51,878 行，原始 30 字段前增加原序号；重复条目、备注、费用摘录、评价和负值均保留 |
| `details.js`   | 院校分包的 `schools`             | 2,308 份完整档案原文，与学校代码对应                                            |

分包的院校记录为 `[原序号, 完整院校对象, 原始档案文本]`；招生专业记录为 `[原序号, ...原始30字段]`。组字段及专业字段名称收录于目录的 `schemas`。原始负值、0、空字符串和 null 保持原义，不将未知改成免费、无限制、无资格或新增。

目录中的院校摘要和 `links` 是检索加速数据。`links` 对同一组的专业/门类/专业类组合去重以便筛选，完整招生条目不去重、不删减。专业、门类、专业类组合必须属于同一条招生记录，避免拼出源数据不存在的匹配。

`data/manifest.json` 记录所有输入文件的原始/语义哈希、输出文件哈希、字节数、记录数和原始覆盖率。检查脚本从分包按原序号重建全部输入，逐值比较；同时核对原始文件未变、文件哈希一致、索引关系闭合。

本仓库提供的是五份导出数据。上游原始观测库未包含在本仓库中，迁移保证针对这里实际存在的全部导出记录与字段。

## 口径与补充资料

- 分数用 2026 年对应科类一分一段表换算位次，再用 2025 年相同位次换算等效分；不直接将两个年份的原始分数相减。高分未完整收录区间显示边界，不给出精确分差。
- 冲稳保描述往年组线与个人位次的比例位置，不是录取概率。2024、2023 旧文理数据独立展示，专业线与组线分开。
- 源表四川填报学费与额外院校收费材料分别展示；后者可能来自其他省份。招生章程、收费原文、完整字段可继续展开核验。
- `resources.json` 是独立、注明出处与核对日期的补充层。已核对四川考试院 2026 招生计划入口及招生规定，本科普通批 B 段和普通高职批显示 45 组容量、每组 6 个专业志愿；其他类别须按对应条款单独核对。未用检索摘要覆盖原始招生值。

## 工作台与旧版数据

专业组标识为 `院校代码|科类|批次|招生类型|专业组代码`。全清单保留不同科类/批次、顺序、备注和偏好专业；界面按当前科类与批次分别显示。导出文字、CSV 和 JSON 均包含完整清单；JSON 支持再次导入。未匹配条目另行保留，并随下次 JSON 备份导出。

可主动导入第一代、第二代收藏，旧版存储不删除、不覆盖。V3 使用独立的 `luodian.v3.*` 键；第一代的数字索引按本次源文件原序映射，后续换源若发生重排，应使用当前版本备份中的稳定标识。

## 验证边界

自动检查覆盖完整数据还原、位次与阈值、未知选科、学费缺失、跨批次保存，以及 Chromium 桌面和触摸模拟的主要流程、320–1440 像素横向溢出、详情重试、主题与减少动态效果。手机模拟不能替代真实 iOS Safari / Android 输入法、浏览器返回手势与系统键盘的实机检查。
