## 这是什么

四川 2026 新高考（3+1+2）的志愿查询工具。以**院校专业组**为志愿单位
（本科批 B 段共 45 个志愿位），帮考生回答三个问题：

1. **我这个位次能填哪些组？** —— 冲 / 稳 / 保分档，分数为主、位次为辅
2. **这个组的线和我差多少？** —— 同口径换算（把你的位次换成上一年的等效分再比）
3. **这些专业值不值得读？** —— 专业级的软科评级、学科评估、硕博点

## 快捷方式

网址后加参数可以直接跳到指定状态，适合存成书签：

```
?score=600&track=0        直接定位到 600 分 · 物理类
?score=600&track=1        600 分 · 历史类
?score=669&group=51       定位后直接打开某个专业组
?stage=1                  演示模式（全屏 + 字号放大，适合投屏/白板）
?noanim=1                 关闭全部动画
#groups / #major / #schools / #plan / #find
```

## 三条必须知道的口径

**① 只有 2025 能与 2026 直接比较。**
2024 及以前是**文理分科**，与现在的物理类 / 历史类不是同一定义，
本站不参与分档，只在详情页作为趋势参考。

**② 分数不能跨年相减，位次可以。**
两年的卷子不同。要看差距，本站会把你的位次换算成上一年的等效分再比
（例：位次 22,303 → 2025 等效 601 分，与组线 572 分相比 +29 分）。

**③ 学费有两个口径，互不覆盖。**
「招生考试报填报」是四川口径、专业级，**你按这个交费**；
「官方收费表」是院校级、按收费类别列，可能来自其他省份的招生计划。
两者不一定对口，**本站不做「一致 / 冲突」判定**。

## 免责

本站提供的是**往年录取位置的对照，不构成录取概率预测**。
专业组可能逐年重组，招生计划、批次与投档规则也可能调整。
正式填报请以学校官网、当年招生章程和四川省教育考试院公布的招生计划为准。
